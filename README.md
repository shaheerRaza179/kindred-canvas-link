# Social Canvas

Build a social media web application frontend, similar to Instagram/Facebook, with the following features:

AUTHENTICATION

- Sign up page (name, username, email, password, profile picture)

- Sign in / login page

- Forgot password flow (UI only)

USER PROFILE

- Profile page showing profile picture, cover photo, bio, name, username

- Followers count and Following count (clickable to show lists)

- Follow / Unfollow button on other users' profiles

- Edit profile page (update picture, bio, name, etc.)

- Grid view of user's own posts on their profile

HOME FEED

- Main news feed showing posts from followed users

- Each post shows: profile picture, username, timestamp, image/text content, like button, comment button, share button

- Like/unlike functionality (UI state toggle)

- Comment section under each post (view comments + add comment input)

- Share button (UI only)

POSTS

- Create post page/modal (upload image, add caption)

- Post detail view (full post with all comments)

SOCIAL DISCOVERY

- Explore/Discover page showing suggested users to follow

- Search bar to search users

MESSAGING

- Direct messages / chat section

- List of conversations (inbox)

- Individual chat screen with message bubbles and input box (real-time look, even if mocked)

NOTIFICATIONS

- Notifications page/dropdown showing likes, comments, new followers, etc.

NAVIGATION

- Persistent sidebar or bottom nav with: Home, Explore/Search, Create Post, Notifications, Messages, Profile

DESIGN REQUIREMENTS

- Professional DARK theme — NOT pure black. Use deep charcoal/slate/near-black navy tones with a tasteful accent color for buttons and highlights

- Clean, modern, premium SaaS-app aesthetic

- Strong typography hierarchy, proper spacing, subtle shadows/borders for depth

- Fully responsive (mobile and desktop)
